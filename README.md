## Cyber Escape – Web-Based Game

Cyber Escape is a browser game I developed using HTML, CSS, JavaScript and Phaser 3 as part of my university coursework.
The game involves collecting stolen data fragments in a computer system and progressing through three increasingly challenging levels.

## Play the Game

The game is available to play online using GitHub Pages:

https://ryanar2004.github.io/Cyber-Escape-Game/

## Technologies Used
- HTML5 and CSS3
- JavaScript
- Phaser 3
- Web Crypto API
- Browser localStorage
  
## Key Features
- Three levels with increasing difficulty
- You only have 10 seconds to complete the game in each level
- User registration and login with password hashing.
- Leaderboard that tracks players highest scores.
